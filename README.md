<h2 align="center">📌 About This Challenge</h2>

<p align="center">
This repository documents my journey through the <b>160 Days Problem Solving Challenge</b> on GeeksforGeeks.
</p>

<p align="center">
⚡ <b>Important Note:</b> The goal is to solve <b>160 problems</b>, not necessarily in 160 days.<br/>
Some days I might solve multiple problems, while other days I might solve one or skip.<br/>
The focus is on completing 160 quality problems to master Data Structures and Algorithms.
</p>
